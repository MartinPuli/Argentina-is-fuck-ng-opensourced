## What the teammate built

Four commits add 37 files under `gate/`: a FastAPI procurement interface, SQLite attachment storage, PDF text extraction and Spanish OCR, deterministic identifier checks, model-assisted text/image review, a human review queue, public downloads checked against stored publication decisions, fictional PDF fixtures and five pytest test functions. The policy prevents a model response from overriding deterministic blocking findings. The public attachment route checks its decision on every request. These are useful implementation choices for the separate publication-exposure problem. It does not establish successful current account access, model availability, a completed hosted session or a same-run three-sponsor demonstration. Tests explicitly clear sponsor settings, and the model-policy test supplies constructed result dictionaries. Those checks cannot establish live integrations. ## Fit with BREACHSTOP

This is a **publication-control module**, applicable to accidentally public attachments. It advances beyond our manifest-only publication experiment by introducing actual PDF/OCR and contextual classification code. It does not implement stolen-credential containment, server-intrusion detection, revocation, isolated code repair, trusted deployment or host recovery. Historical PAMI reporting also does not prove that every unknown government incident followed this publication mechanism.

Guild currently receives a case and returns a reviewer brief. Its agent configuration declares no integrations, subagents or builtins; the human makes the publication decision. This is not the proposed autonomous external-action loop. Retain the module alongside the main [defense proposal](WHAT-TO-BUILD.md), and require separately observed sponsor operations and authorized open-web action before claiming the complete [event requirements](../EVENT-BRIEF.md). [Guild configuration](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/guild-agent/guild.yaml#L22-L24), [session/brief adapter](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/src/gate/agent.py#L53-L68).

## Three material findings

### 1. Missing staff configuration exposes the internal attachment path

When `GATE_STAFF_PASSWORD` is absent or empty, `staff()` returns a user without authentication. `/internal/file/{att_id}` then serves any stored PDF regardless of its public decision. The same dependency protects review actions, so an anonymous visitor could approve held files in this configuration. The example explicitly labels this local-development behavior; it must not survive a public demonstration or deployment. A 404 on the public-file path alone therefore does not prove the private attachment is inaccessible. [Authentication default](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/src/gate/app.py#L45-L51), [internal download](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/src/gate/app.py#L214-L221), [documented development default](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/.env.example#L14-L15).

**Remediation and checks:** reject startup or protected access when authentication is unconfigured outside an explicit local-development mode. Test unauthenticated internal downloads and approval requests with missing, empty and configured credentials. For accountable review, use distinct authenticated reviewer identities and permissions; the current audit name comes from an editable form field, and the shared-password check accepts any supplied username. Test that a request cannot attribute approval to someone else. [Reviewer attribution](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/src/gate/app.py#L167-L182).

### 2. Mixed text/image pages skip both visual checks

`extract()` stops inspecting a page visually once extracted text reaches 25 characters. Only the alternate OCR branch creates `Page.image`, and `evaluate()` invokes vision only when that image exists. A page containing a sufficiently long benign text header and a sensitive embedded image therefore bypasses OCR and vision. This is a specific content-coverage gap, even when the text model is configured. [Early text-only return](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/src/gate/detect.py#L48-L59), [conditional vision call](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/src/gate/app.py#L61-L67).

**Remediation and checks:** decide visual coverage independently of text length. Inspect image-bearing/mixed-content pages or hold them when required analysis is unavailable. Add a synthetic PDF with more than 25 harmless text characters plus an embedded identity or medical image, alongside a harmless-image control. Verify classification and unauthenticated response bytes. Existing generated fixtures separate text PDFs from image-only scans and do not cover this combination. [Fixture constructors](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/fixtures/make_fixtures.py#L28-L64).

### 3. Unavailable contextual analysis can release a known risky text case

The policy starts from `PUBLIC`; its model-error fallback changes that to `HOLD` only for OCR-derived documents. With no configured model, or an error on an ordinary text document, absence of a deterministic match can therefore publish the file. The offline fixture expectations explicitly classify the bed specification as public despite noting that only the model catches its risk; its generated content combines age, town, operation, hospital and date. This contradicts an unconditional claim that private attachments never reach the portal. [Default and fallback](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/src/gate/policy.py#L30-L65), [known test expectation](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/tests/test_gate.py#L21-L37), [fixture content](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/fixtures/make_fixtures.py#L158-L165).

**Remediation and checks:** declare which analyses are required for automatic publication and represent missing/failed coverage explicitly. Hold affected files for review rather than interpreting an unavailable check as safety. Test no key, timeout/error, malformed result and complete safe result, including the known bed fixture and legitimate public specifications. Qualify the [README's opening guarantee](https://github.com/MartinPuli/Argentina-is-fuck-ng-opensourced/blob/73b05484cfa513dd01a043323c973c9f160a4a6e/gate/README.md#L1-L3) until measured content coverage supports a narrower statement.

## Evidence still required

Run the local tests and the added regressions in an isolated synthetic environment; preserve source/dependency revisions and actual observations. Separately verify configured sponsor calls with sanitized receipts and failure states. In a controlled public demonstration, use an independent unauthenticated client to check exact sensitive fixture content across every accessible route, not only filenames or dashboard decisions. Keep all sponsor inputs fictional: the Akash adapter transmits extracted text and rendered page images to its configured provider, so an open model is not evidence of local-only data processing.
