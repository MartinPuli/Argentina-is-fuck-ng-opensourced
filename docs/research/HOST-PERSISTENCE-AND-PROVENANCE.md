## HPP-01 / AD10 — SoK: Systematization, Detection, and Hunting of Windows Malware Persistence Techniques

AsiaCCS 2026, June 1–5; institutional publication metadata: June 2026. Earliest public date and revision history remain unresolved. [Institutional record](https://research.utwente.nl/en/publications/sok-systematization-detection-and-hunting-of-windows-malware-pers/), [reviewed PDF](https://www.eurecom.fr/publication/8692/download/sec-publi-8692.pdf).

API/WMI rules detect known persistence; artifact filtering supports manual discovery. Validation detects 72/72 authored technique PoCs; manual review finds two false positives among 334 selected samples. Of 85,424 submitted samples, 48,873 survive activity filtering. Section 4.5 reports persistence in 55.2% of Dataset I's 40,522 retained samples and 41.3% of Dataset II's 8,351; denominators follow subtraction in §4.2. The abstract's apparent pooled 55.2% is misleading. Windows 10 sandbox observations last 200 seconds; inactive/evasive samples and unobserved behavior limit coverage. Tool comparisons use the authors' detector as ground truth and translate snapshot-tool patterns into rules. Inference for BREACHSTOP: absent persistence cannot establish absence of credential theft. Keep credential containment separate from endpoint eradication; test self-deleting activity, multiple persistence paths and delayed triggers through an independently verified endpoint workflow. Our current component does not establish host recovery. [Methods §§2–3; validation §§4.1–4.3; comparisons §4.5/Table 4; implications §5](https://www.eurecom.fr/publication/8692/download/sec-publi-8692.pdf).

## HPP-02 / AD13 — Slot: Provenance-Driven APT Detection through Graph Reinforcement Learning

Earlier foundation: first preprint 2024-10-23; reviewed arXiv:2410.17910v4, 2025-07-17. CCS 2025 conference: October 13–17. [Version history](https://arxiv.org/abs/2410.17910), [versioned full text](https://arxiv.org/html/2410.17910v4), [author's conference PDF](https://yebof.github.io/assets/pdf/qiao2025ccs.pdf).

Slot combines provenance embeddings, reinforcement-guided neighbor selection, supervised/anomaly detection and ATT&CK-assisted clustering. Table 4 reports TRACE detection of 60,604/60,644 malicious entities, with 1,521/613,050 benign entities flagged; these are entity counts, not incidents prevented. Audit integrity is assumed. Evaluation uses existing datasets; mimicry tests insert benign graph structures. Unknown-anomaly false positives, concept drift and untested white-box attacks limit claims. Temporal holdout and repeated-trial uncertainty are not established in the reviewed sections. The conference PDF changes some StreamSpot values from v4; only matching Table 4 TRACE counts are used here. Inference: preserve raw-event evidence beside reconstructed chains and test missing/tampered logs and benign mimicry separately. Detection cannot authorize credential revocation, demonstrate host eradication or establish recovery. [Assumptions §3.2; methods §4; counts §5.2/Table 4; robustness §5.7; alert validation §5.8; limitations §5.9](https://arxiv.org/html/2410.17910v4).
